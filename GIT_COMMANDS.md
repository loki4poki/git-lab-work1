# Основные команды Git

### 1. `git init`
* **Назначение:** Создает новый пустой локальный репозиторий Git в текущей директории.
* **Как пользоваться:** Перейти в папку проекта и выполнить команду без параметров.
* **Пример:** `git init`

### 2. `git clone`
* **Назначение:** Создает полную локальную копию существующего удаленного репозитория.
* **Как пользоваться:** Указать URL-адрес репозитория после команды.
* **Пример:** `git clone https://github.com`

### 3. `git add`
* **Назначение:** Добавляет изменения в рабочих файлах в индекс (подготавливает к коммиту).
* **Как пользоваться:** Указать имя файла или `.` для добавления всех файлов.
* **Пример:** `git add README.md`

### 4. `git commit`
* **Назначение:** Фиксирует проиндексированные изменения в истории репозитория.
* **Как пользоваться:** Выполняется с флагом `-m` и комментарием.
* **Пример:** `git commit -m "Добавлен файл"`

### 5. `git push`
* **Назначение:** Отправляет локальные коммиты в удаленный репозиторий.
* **Как пользоваться:** Указать имя удаленного репозитория (`origin`) и ветку.
* **Пример:** `git push origin main`

### 6. `git pull`
* **Назначение:** Загружает изменения из удаленного репозитория и сливает их с текущей веткой.
* **Как пользоваться:** Выполнить в нужной ветке или указать репозиторий и ветку.
* **Пример:** `git pull origin main`
